# Eddie Miller Agency

Site public : https://eddiemiller.agency

Refonte préparée par Codex, publiée à la demande du propriétaire le 6 septembre 2026. Sources : offre fournie par le propriétaire et code du site existant.

Astro, CSS Tailwind, polices et illustrations locales. Sept langues, trois expertises : visibilité IA et Google Maps, automatisation des tâches, création de sites web.

## Développement

`npm ci`, puis `npm run dev`. `npm run build` construit un aperçu sans indexation ni envoi.

## Publication

Vercel construit la branche de production avec `scripts/build-vercel.mjs`. Les autres branches restent en aperçu. Le mode public prépare un email dans la messagerie du visiteur ; aucun envoi automatique n’est simulé.

Lire `AGENTS.md` avant toute modification.
