A directory, a map listing and an appointment calendar answer different questions. Check each detail where it can actually be corrected.

## What to check

1. For identity and practice location, compare the professional directory and practice website. Watch for namesakes and dentists working at several sites.

2. For directions, check the pin and read the practice’s entrance instructions. For booking, check the location and appointment type in the dentist’s calendar.

3. If sources conflict, save both links and ask the practice. Seeing a link in an answer does not tell you how heavily an assistant weights that source.

## When addresses disagree

A PagesJaunes listing might still show the old premises while the booking calendar already shows the new location. Compare the practitioner’s name as well as the practice name. Record when you checked both pages and call reception before editing a listing you manage.
